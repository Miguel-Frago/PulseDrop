# PulseDrop (Capacitor + GitHub Actions)

1. Create a new GitHub repo and push this folder to it (branch main).
2. Open the Actions tab, run "Build Android APK" (it also runs on every push).
3. When it finishes, download the artifact "pulsedrop-debug-apk" and install app-debug.apk.

Game code lives in www/index.html. Character art goes in www/img/.
